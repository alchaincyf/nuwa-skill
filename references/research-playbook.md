# 采集手册

采集阶段照着走时读这份。目标只有两个：拿到足够多的一手材料；专门找和先验不一样的东西。

## 目录

1. 开工前：本地素材、可用工具、档位
2. 六路分工
3. 任务书模板

5. 中文人物与英文人物

## 1 · 开工前

**本地素材。** 用户给了书、访谈原文、字幕、博客导出，先放进 `$OUT/references/sources/`，按六路归类（一本书可能同时喂给著作、对话、表达三路），
看哪几路已经够了、哪几路还空着，只对空着的做网络搜索。用户明确说「只用我给的」或对象是非公众人物时，不做网络搜索。
底稿里把「来自用户素材」和「来自网络」分开标。

| 素材 | 怎么用 | 主要喂给 |
|---|---|---|
| 书籍 PDF | 通读，提核心论点和他讲自己经历的段落 | 著作、决策、表达 |
| 演讲、访谈的文字稿或字幕 | 看问答方式和即兴反应 | 对话、表达 |
| 博客、newsletter 导出 | 提反复出现的观点 | 著作、表达 |
| 社交媒体导出 | 看碎片表达 | 表达 |
| 内部文档、备忘录 | 看决策逻辑 | 决策 |
| 用户自己整理的笔记 | 当二手来源交叉参考 | 视内容 |

**可用工具。** 看一眼运行环境里有没有比通用搜索更合适的信息获取能力（多平台抓取、网页全文读取、PDF 读取、视频转写之类的 skill 或工具），
有就在任务书里告诉各路可以用。没有也不影响，通用的搜索和网页读取够用。

**档位。** 快速档只跑著作、对话、决策三路，每路约 5 个来源；标准档六路；深度档六路并把一手素材原件存进 `sources/`。

## 2 · 六路分工

| 路 | 找什么 | 重点提什么 | 写到 |
|---|---|---|---|
| 1 著作 | 书、长文、论文、newsletter | 反复出现三次以上的论点、自创术语、他推荐的书 | `01-writings.md` |
| 2 对话 | 播客、长视频、问答、深度采访 | 被追问时怎么答、即兴打的比方、当场改口的瞬间、拒绝回答的问题 | `02-conversations.md` |
| 3 表达 | 社交媒体、短文、公开信 | 高频用词和句式、有争议的表态、幽默方式、和人吵架时的样子 | `03-expression-dna.md` |
| 4 他者 | 传记、书评、同行评价、批评文章 | 外人看到的模式、主要的批评与争议、和同行的差别 | `04-external-views.md` |
| 5 决策 | 重大决策、转折、有争议的行为 | 当时的处境和选项、他做了什么、事后怎么说、言行不一的地方 | `05-decisions.md` |
| 6 时间线 | 从出道到现在 | 关键节点、思想转折、最近 12 个月的动态 | `06-timeline.md` |

第 5 路最值钱，也最容易做浅：要的是过去时的叙事（哪年、什么处境、他具体做了什么、后来怎样），每件事尽量找到他自己的解释。
第 4 路是防粉丝滤镜的：负面评价不足，这次调研不算合格。

## 3 · 任务书模板

派子代理时用这个结构（以第 5 路为例，其余各路换掉「找什么」和文件名）：

```
你的任务：调研[人名]的重大决策与实际行动。

先读 [$OUT]/references/research/00-prior.md ——这是调研前对他的已有认识。你的工作重点是找和它不一样的东西。

找什么：
- 他职业生涯里的重大决策、转折点、有争议的行为
- 每件事要有：哪一年、当时的处境和可选项、他具体做了什么、结果、他事后怎么解释（尽量找到原话）
- 他说的和做的不一致的地方
- 失败、后悔、改口的事和成功的同样重要

要求：
- 写入 [$OUT]/references/research/05-decisions.md，边查边写，不要等全部查完
- 每条标来源链接和可信度（一手 / 二手交叉印证 / 单一二手）
- 分清「他说的 / 他做的 / 别人说他的 / 我推断的」
- 用过去时写他做过的事，不要概括成态度
- 发现互相矛盾的说法直接并列记下，不要调和
- 引语必须是查得到原文的，查不到就不加引号
- 文件最后单列一段「和先验不一样的地方」，每条标：推翻 / 加深 / 新增

不用的来源：知乎、微信公众号、百度百科、百度知道。

查了约 [N] 个来源或连续几次搜不到新东西就收，把没查到的维度写在文件末尾。
```

## 4 · 信息源

| 来源 | 能看出什么 | 权重 |
|---|---|---|
| 用户提供的一手素材 | 完整原文，没被转述过 | 最高 |
| 本人著作与长文 | 系统性的思考 | 最高 |
| 长对话、访谈原文 | 即兴的思考过程 | 最高 |
| 实际的决策记录 | 真实行为，对照他的说法 | 最高 |
| 社交媒体 | 表达风格、即时反应 | 中 |
| 他人的评价 | 外部视角、盲点 | 中 |
| 二手转述 | 可参考，要找原文验证 | 低 |

永远不用：知乎（洗稿、失真）、微信公众号（无法验证、多为二手转述）、百度百科和百度知道（陈旧、不可靠）。

## 5 · 中文人物与英文人物

- **中文人物**：视频平台上的原始演讲和访谈（不要搬运号）、播客原始音频、权威媒体的采访（晚点、财新、36氪、极客公园、第一财经、虎嗅、少数派、机器之心等）、本人著作、本人微博。
- **英文人物**：本人的博客与社交账号、视频平台上的长访谈、播客及其文字稿、书和书评。
- **在世的人**：注意时效，最近 12 个月的动态必查，写明截止日期。
- **已故的人**：材料稳定，但传记有偏向，多个来源交叉印证。

## 6 · 字幕与书籍

长访谈的视频是最好的一手材料之一：

```bash
bash $NUWA/scripts/download_subtitles.sh <视频网址> $OUT/references/sources/transcripts   # 优先人工字幕，其次中文、英文、自动字幕
python3 $NUWA/scripts/srt_to_transcript.py <字幕.srt> <输出.txt>                              # 去时间戳和重复行，变成可读文本
```

用户给的是没有字幕的本地视频，用运行环境里的视频转写能力处理；没有就请用户提供文字稿。
书籍用用户提供的文件，或公开可得的合法来源；拿不到全书时用作者公开的章节、演讲和长书评，并在底稿里写明。

## 7 · 挑封存件

采集全部完成、动手提炼之前，从一手材料里挑 3–5 件，记进 `research/holdout.md`：

```markdown
## H1
- 出处：[链接或书名页码]，[年份]
- 问题：[一个能直接拿去问的问题，不透露答案]
- 他实际怎么说 / 怎么做：[要点 3–5 条，尽量带原话]
- 为什么选它：[立场明确 / 细节具体 / 不是人尽皆知]
```

挑的标准：

- **优先挑决策和处境**：一个有岔路的具体处境——他当时有别的选择，最后怎么做的、理由是什么。问题写成「当时面对 X，你会怎么做、为什么」
- 其次是他对一个具体问题的**完整回答**（有论证过程的一段话，不是一句话）
- 每件能写出 3–5 条要点
- 过两问：熟读他的人大概率答得对吗？不了解他的聪明人大概率会答错或答得泛吗？两个都是「是」才合格
- 分散在不同话题上，一手来源，查得到原文

不要挑的：

- **金句和单句表态**。一句话的原话（「最大的问题是信心不够」）没法从他的思路推出来，只能靠背；拿它当考题，测的是记没记住这句话，不是 Skill 有没有抓住他怎么想。实测里用了四条微博金句当封存件，带 Skill 的答卷有案例、有边界标注，分数反而比裸答低
- 人尽皆知的大事件（模型早就背下来了，两臂都满分，测不出差别）。越有名的人越要避开他的著名决策，去挑长访谈里的小判断
- 开放到怎么答都对的问题（「创业者最需要什么」）

之后这几件材料只当考题，不当证据：对应的内容不写进招式、案例卡和原话库。
升级旧版 Skill 时底稿已经被消化过，封存件优先从补搜到的新材料里挑；只能从旧底稿里挑时，在 holdout.md 开头如实写明。
但别把新材料全封了：补搜到的新东西正是模型最不知道的，全拿去当考题，Skill 里就没有增量了。新材料里封存和进案例库的大致各一半。
验证做完以后，封存件可以解封写进案例库，在 FIDELITY.md 里注明哪几件是测完才收进去的。

升级时散落在别处的旧底稿，一律先收进 `references/research/` 下的一个子目录（如 `legacy-YYYYMM/`）再用；补搜的新底稿接着编号（`07-…md`）。

## 8 · 没有子代理、窗口不够、搜不了时

| 情况 | 怎么办 |
|---|---|
| 运行环境没有子代理，或后台任务会挂起死等 | 六路串行：做完一路、落盘一路，再做下一路。不要等后台通知 |
| 上下文窗口不够（完整蒸馏会累积五十万 token 以上，200k 窗口跑不完） | 分三个会话：定题到采集 / 封存到提炼 / 成形到验证。每段开头先读已落盘的底稿。底稿就是断点 |
| 搜索工具不可用 | 用环境里别的等价工具（网页读取、浏览器）；都没有就转纯本地素材，请用户提供 |
| 用户中途喊停 | 已落盘的底稿就是可交付的中间产物，下次接着做 |

## 9 · 出了状况怎么办

| 状况 | 处理 |
|---|---|
| 某一路搜了五分钟没有有价值的结果 | 不等，往下走；提炼时标「信息不足」，写进边界 |
| 可用来源不足 10 条 | 立刻告诉用户质量会受限；模型减到 2–3 个，边界加大篇幅，跳过封存 |
| 各路结果互相矛盾 | 保留，这是有价值的信号，进「我没想清楚的事」 |
| 「和先验不一样的地方」合计不到 8 条 | 说明还在复述常识：换更深的来源——长访谈原文、早期文章、当事人的回忆、批评者的文章 |
| 找到的引语查不到原始出处 | 不用 |
