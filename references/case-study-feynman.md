# 案例：费曼方法层提取与预测验证（公开语料，协议可复跑）

> 本案例是「方法动作提取＋预注册预测测」协议（Phase 2.7 / 4.4）的完整实证。
> 语料全部公开可得，任何人都可按同一协议复跑验证。

## 一、动机：一次真实的转化链丢失

用女娲现有协议蒸馏费曼（对照组为本仓库已发布的 feynman-skill），体检发现：

| 动作 | 在其调研文件中有事实记录？ | 在SKILL.md运行时指令中？ |
|------|--------------------------|------------------------|
| M4 独立验证（亲手复核出教科书数据造假） | ✅ 有 | ❌ 无 |
| M3 定量估算（数未知数、量级估算） | ✅ 有 | ❌ 无 |
| M7 自造工具换表述（自造sigma记号、路径积分第三种表述） | ✅ 有 | ❌ 无 |

**事实采到了，提炼时被过滤成了价值观原则**（「重视实证」「好奇心」）。这不是采集问题，是「采集→提炼」转化链的问题——需要协议层的检查项，而不是更努力的调研。

## 二、协议执行过程

1. **抽样框**：语料按体裁分层（自传章节/公开演讲/访谈/官方报告），每条验证存在后进框。一例「记忆中的对话」经全网+全书12.5万词检索零命中，判定记忆混源，作废——**框内条目必须先验存在**
2. **预注册**：评分前写死预测文件（时间戳锁死）
3. **扣置**：分层随机抽8篇（种子写死），提取时不读；1篇OCR缺陷作废，分母=7
4. **盲评**：无上下文子agent通读7.1万词，只拿动作定义+原文，0/0.5/1打分，1分必须附≥2句连续引文
5. **判定**：断言逐条判生死，密度只记录

## 四、结果

**动作密度（扣置7篇盲评，分母7）**：

| 动作 | 密度 | 备注 |
|------|------|------|
| M3 定量估算 | **7/7** | 数未知数/量级估算/参数拟合审查 |
| M5 阴性边界诚实 | **7/7** | 「没人知道为什么」照说+边界立刻标 |
| M6 第一性倒推 | **7/7** | 从物理原理推，不从经验式凑 |
| M1 命名≠理解 | 6.5/7 | 知道名字≠懂了，能用才是懂 |
| M2 具象化转译 | 6.5/7 | 一切翻成可感知画面 |
| M4 独立验证 | 6.5/7 | 争端以自己做实验收场 |
| M7 自造工具换表述 | 6.5/7 | 常规路死则换表述/自造记号 |

满格率91%（45格41个满分）。另得清单外新动作24个（带引文），其中跨篇复现2个。

**预测测（断言级3/3全中）**：全域高密度✓／M3/M4/M7存在✓／现有skill不覆盖此三项✓。

**一个诚实的失败（方法学产出）**：格级密度预测仅41%命中，全部单向低估——败因是提取者带着上一个人物「密度约40%」的先验。由此固化协议规则：**预注册只押方向（是否出现），不押密度**。

## 五、给协议使用者的三条经验

1. **转化检查要逐条对账**：调研文件里的做法/事件清单 vs SKILL.md运行时指令，逐条对——丢的最多的不是冷门内容，是「具体做法被抽象成品质」的高频动作
2. **叙事过去时才算动作**：他做了X（记叙）vs 他觉得应该X（规约）——后者是价值观，混进动作清单会让方法层注水
3. **推翻是产出**：预注册断言被推翻时，回写交付文档。本案例格级预测失败直接产出了「不押密度」规则

## 六、三申报（本案例自己的保质期）

- **盲区**：扣置7篇非全量；书信/课堂实录未入语料；自传为晚年口述，动作细节存美化风险；单评分员
- **先验**：动作词汇部分与本仓库现有feynman-skill同词根（同词不同证——对方缺的恰是M3/M4/M7，实测均为满频，已部分排除）
- **推翻口**：若未入语料体裁（书信/题解）出现M3/M4/M7系统性缺席→「全域高密度」降级为「公开演讲体裁密度」；若本仓库feynman-skill后续版本补上M3/M4/M7运行时指令→「转化链丢失」结论过期
