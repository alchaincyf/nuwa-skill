# 方法层提取模板（Phase 2.7 / 4.4 / 4.5 配套）

> 心智模型回答「怎么想」，表达DNA回答「怎么说」，方法动作回答「怎么干」。
> 本模板供 Phase 2.7 提取、Phase 4.4 预测测、Phase 4.5 生手测三处使用。

## 一、动作清单表（Phase 2.7 产出）

| # | 动作名 | 一句话定义 | 语料证据（≥2处，引原文+来源） | 频率分母 | 反例戳（何时不做） |
|---|--------|-----------|------------------------------|---------|------------------|
| M1 | （例：数量级估算） | （遇到关键量先估数量级再谈结论） | （原文摘录＋篇目/页码）×2 | 7篇中7篇 | （例：纯价值判断话题不估） |

**打分纪律**（提取时自查）：
- 叙事过去时（他做了X）→ 实质动作
- 规约语气（他觉得应该X）→ 价值观，**不入**动作清单
- 每个动作必须是可观察行为，不是品质（「严谨」❌「亲手复算数据」✅）

## 二、转化检查表（Phase 2.5 检查项用）

| 调研文件中的事实（做法/事件） | 对应SKILL.md运行时指令 | 状态 |
|------------------------------|----------------------|------|
| （例：他亲手复核教科书数据，发现造假） | （例：研究步骤第2步「关键数据先复算再引用」） | ✅已转化 |
| （例：他用自造符号简化推导） | （无对应） | ❌丢失，需补 |

> 经验教训：转化丢失的高发形态是「具体做法 → 抽象品质」（亲手复核→「重视实证」）。
> 抽象后看着没问题，但运行时指令失去了「做什么」。

## 三、预注册模板（Phase 4.4 开卷前写死）

```markdown
# [人物] 方法动作预测 · 预注册（写死于盲评前）
时间：YYYY-MM-DD HH:MM（锁死，此后不改）
扣置篇目：[列表，随机种子=____]

## 断言级预测（押方向，不押密度）
| # | 断言 | 推翻口 |
|---|------|--------|
| 1 | 动作[X]在≥N/M篇中实质出现 | <____篇 |
| 2 | 存在清单外新动作≥1个 | 0个 |

## 污染申报
- 扣置篇目被提取者读过的级别：[精读/开头段/摘要/未读]
- [其他已知污染源]

## 汇总规则
盲评0/0.5/1；实质动作=≥2句连续原文支撑＋引文必附；断言逐条判生死；密度只记录不预设。
```

**为什么只押方向不押密度**：密度预测会被提取者对「典型频率」的先验污染（上一个案例的密度会锚定这一次的预期），实证两案均单向失准。方向断言（出现/不出现）则稳定可信。

## 四、盲评指令模板（spawn 无上下文子agent）

```
你会读到[人物]的[M]篇文本和一份动作定义清单。
逐篇 × 逐动作打分：
1 = 实质动作：≥2句连续原文支撑此动作确实发生（必须摘录引文）
0.5 = 提及：谈到此动作但未实际执行（规约语气、引用他人做法均算0.5）
0 = 无
输出矩阵表：篇目×动作，每格分数+引文（1分的必须带）。
不要猜测清单外意图，只按定义判定。
```

## 五、入手卡模板（Phase 3 交付物，Phase 4.5 生手测对象）

```markdown
# [人物] 方法论·入手卡（[场景]）
> 用法一句话。拿一个正在处理的对象，按[N]个动作走。断点落在「材料没给」处就报缺口，不硬编。

1. **动作一·[名]**：[一句可执行指令]
2. **动作二·[名]**：[一句可执行指令]
3. ...
- **验收信号**：第一次说出「______」＝回路通了
```

**入手卡写作纪律**：
- 无黑话——卡片面向未读过提炼文档的用户，内部术语全部展开成白话
- 每个动作独立可执行，不依赖「先理解框架」
- 验收信号是一句用户会说出来的话，不是一个内部标准

## 六、三申报模板（Phase 2.6 交付物）

```markdown
- **盲区申报**：本语料看不见什么（未收录体裁/已删内容/代工可能/静默功课）
- **先验申报**：提取过程可能投射了什么（与前人框架同形处/提取者偏好）
- **推翻口**：若______出现 → ______结论作废
```
